# Fonts

The poster fonts are free-licence Google Fonts. `install.sh` downloads them from the google/fonts repository at a pinned
commit and checks each file's SHA-256 against `fonts.lock`, so every install renders identically. The font binaries aren't
committed here. They're fetched from their upstream source.
